# Creative Studio 構想書

## プロジェクト概要

**Creative Studio** は、漫画と小説の両方の制作が可能な統合 Web アプリケーションです。ユーザーはボタン一つでモードを切り替えて、視覚的なコンテンツ制作とテキストコンテンツ制作を行うことができます。

---

## 主要機能

### 🎨 漫画制作モード

**ワークフロー：**
- ラフ画像のアップロード
- キャラクター・ストーリーの入力
- DALL-E による自動画像生成
- プレビュー表示 → 完成

**特性：** 視覚的、短期制作（1セッション）

---

### ✍️ 小説制作モード

**ワークフロー：**
1. テーマ・ジャンル選択
2. キャラクターシート作成
3. プロット構成（3幕法など）
4. テキストエディタで執筆
5. 推敲・統計表示
6. エクスポート（.txt / .docx）

**特性：** テキスト中心、長期制作（複数セッション）

## 技術構成

| 層 | 技術スタック |
|----|------------|
| **フロントエンド** | Next.js + React + TypeScript |
| **バックエンド** | Next.js API Routes |
| **データベース** | Supabase (PostgreSQL) |
| **AI API** | OpenAI DALL-E (画像生成) |
| **デプロイ** | Vercel |
| **開発環境** | OpenAI Codex |

## データベース設計（概要）

**テーブル：**
- `users` - ユーザー情報
- `manga_projects` - 漫画プロジェクト
- `manga_images` - 生成された漫画画像
- `novel_projects` - 小説プロジェクト
- `novel_scenes` - 小説のシーン
- `characters` - キャラクター情報

## 実装の特徴

✅ **モード統合** - 1つのアプリで両方の制作方法に対応

✅ **異なるワークフロー** - 漫画と小説で全く異なる UI/UX 設計

✅ **著作権対応** - Kindle 本は著作権フリー画像・自作スクリーンショットのみ使用

✅ **並行開発** - アプリ開発とドキュメント作成を同時進行
